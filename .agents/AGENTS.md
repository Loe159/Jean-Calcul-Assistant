# Instructions pour les skills de développement

Chaque skill est un dossier `skills/<nom>/SKILL.md` avec frontmatter name/description.
Ces instructions servent aux agents de développement ; ne pas les confondre avec les extensions
produit de phase 4. Aucune permission Android ni autorisation externe ne peut en être déduite.

Le skill référence les specs et fiches canoniques, sans recopier leurs exigences en concurrence.
Les références sont relatives au dépôt ; l'exécution ne doit dépendre d'aucun plugin installé
sur la machine ayant rédigé le skill. Garder le chemin direct utilisable par tout agent texte.

Conserver des descriptions discriminantes. Tester liens/structure avec check_agent_docs.py et
relire un scénario de mission réel pour vérifier que l'agent sait quoi lire, changer et prouver.
