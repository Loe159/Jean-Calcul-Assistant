# Conventions

Conserver les composants COUI natifs de `ui/components/coui`, les stores de `ui/app`, les repositories de `data/repository`, les schémas de `agent/model` et les permissions de `agent/tool`. Ne pas inventer un second runtime ou un deuxième stockage. Les types/tableaux amont non exposés peuvent rester pour compatibilité sans réactiver les fonctions exclues.
