# Extension

Lire le périmètre validé puis chercher la fonctionnalité dans les catalogues, contrôleurs et tests amont avant de coder. Pour un nouvel outil : schéma dans `agent/model`, prérequis dans `AgentToolRequirements`, exécution dans le contrôleur concerné, catalogue UI et vérification de refus après retrait de permission. Ne pas modifier la sélection produit sans demande.
