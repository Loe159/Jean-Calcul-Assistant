Les deux dépôts sont clonés. Branche locale de travail : `audit/eta-inventory`, issue de `feature/jean-calcul-v2-foundation`. Aucun code applicatif modifié, aucune reprise ETA encore effectuée, aucun push.

La référence existante de Jean-Calcul (`e2e/references.json`) épingle ETA `4101bc700be7c13b7b72f85a59c1c320f2183c04` comme inspiration visuelle. Le présent inventaire porte sur le code ETA actuel cloné, plus riche. Les anciennes exclusions V2 ne sont pas utilisées pour retirer des options de cette liste : la nouvelle demande est de choisir librement les fonctions ETA à reprendre.

## Comment choisir

Indiquer les numéros à conserver, différer ou exclure. Tous les blocs restent **à décider**. Une sélection peut descendre au niveau des sous-fonctions décrites. « Sans root » désigne le chemin présent dans ETA, pas une validation sur le Samsung de l’utilisateur. Les dépendances entre blocs seront fixées après sélection.

## Fidélité visuelle et approche de reprise

Pour conserver exactement les composants, la navigation et les comportements sélectionnés, la voie la plus directe est une base dérivée d’ETA, puis retrait des blocs non retenus et intégration de l’identité Jean-Calcul. C’est une recommandation d’architecture, pas une migration déjà engagée. La V2 et son parcours APK/E2E restent disponibles comme référence de livraison.

ETA propose COUI (défaut du code audité) et Miuix. COUI est en alpha11 dans ETA, contre alpha7 dans cette V2 : une simple reproduction des captures avec l’ancien kit ne garantit pas le même comportement. Les captures chat et réglages du dépôt ont été réellement ouvertes ; aucun APK ETA n’a été lancé pour cet inventaire. La fidélité des animations, de la voix, du routage Power et de One UI reste à tester sur appareil. Les données/intégrations ColorOS ne deviennent pas compatibles Samsung par renommage de l’application.

ETA indique GPL-3.0 dans son README et fournit la licence dans LICENSE. Une reprise doit conserver sa licence et ses attributions ; la stratégie de distribution devra en tenir compte. Aucun changement de licence du projet Jean-Calcul n’est effectué ici.

## Limites vérifiées

- Plateforme amont : Android 13+, ARM64. L’émulateur x86_64 actuellement utilisé par la V2 ne suffit pas à valider les composants natifs ETA, fournis en ARM64.
- La voix intégrée utilise les API cloud listées ; le runtime local n’implique pas une inférence ou une voix hors ligne. Pas de hotword Eta permanent annoncé ; le déblocage hotword Gemini est une intégration distincte.
- La connexion à un LLM du homelab peut passer par un endpoint compatible. Un connecteur Mastra spécifique n’est pas une fonction ETA confirmée : ne pas le présenter comme existant.
- Commandes de fond, démons, alarmes et agenda ne prouvent pas un moteur d’automatisations récurrentes générique. Aucun moteur de type cron produit n’est confirmé par cet audit.
- Le texte chinois du README et les sources sont plus récents sur certains détails que le README anglais. Le classement des prérequis privilégie AgentToolRequirements, AgentPhoneToolCatalog et ROOTLESS_SUPPORT.
- Présence de code et de tests amont ≠ résultat sur le téléphone. Aucun build, test Android ou essai physique n’a été exécuté pour ce travail documentaire.
