# Tests de référence amont hors périmètre

Les tests des sauvegardes, imports de fournisseurs communautaires, configurations Gemini et presets cloud sont conservés ici sans modification, car ces fonctions ne font pas partie du produit sélectionné.
Le test repository historique, basé sur douze fournisseurs et leurs presets, est remplacé par des tests de persistance vLLM/ChatGPT dans le source set produit. Les tests du stockage, migrations, runtime, transports, outils Android, voix, fichiers, mémoire, MCP et skills restent exécutés.
Les attentes de catalogue/style/terminal sont adaptées à la sélection, sans désactiver les contrôles des fonctions conservées.
