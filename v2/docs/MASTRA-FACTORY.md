# Mastra Factory

Mastra Factory is a separate service, not part of the Android app.
See https://factory.mastra.ai/ and https://github.com/mastra-ai/template-factory.
Connect repository Loe159/Jean-Calcul-Assistant through Factory GitHub App.
In Settings > Work Intake > GitHub issues, enable Sync GitHub issues.
Open a [V2] issue from Work > Intake; use Investigate, plan, implement, review.
Agents must read v2/AGENTS.md, work on a V2 branch and target
feature/jean-calcul-v2-foundation in the PR. Review CI artifacts and approve
manually. Avoid auto-approval until visual testing and policies are qualified.
